2️⃣ SEGURIDAD IMPLEMENTADA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A) CONTENT SECURITY POLICY (CSP)
   📁 Archivo: next.config.ts
   
   ✅ default-src 'self' → Bloquer scripts de terceros no autorizados
   ✅ script-src whitelist → Solo scripts de Vercel, CDN, etc.
   ✅ style-src + fonts → Google Fonts autorizado
   ✅ img-src data: → Permite data URIs (QR codes)
   ✅ frame-src mercadopago.com → Checkout embebido permitido
   ✅ frame-ancestors 'none' → No puede ser framed (clickjacking)
   
   Protege contra:
   - XSS en search (?q=<img src=x onerror=alert()>)
   - Inyección de scripts maliciosos
   - Robo de cookies/tokens

B) RATE LIMITING
   📁 Archivo: lib/rate-limit.ts
   📁 Usado en: app/api/mercadopago/checkout/route.ts
   
   ✅ Máx 3 requests/minuto por IP
   ✅ Responde 429 si se excede
   ✅ Previene DoS (Denial of Service)
   ✅ Previene fuerza bruta en pagos
   
   Implementación:
   - In-memory store (rápido)
   - Reseta cada 60 segundos
   - Identifica por IP remota (x-forwarded-for)

C) OTROS HEADERS SECURITY
   ✅ X-Frame-Options: DENY → Previene clickjacking
   ✅ X-Content-Type-Options: nosniff → Previene MIME sniffing
   ✅ X-XSS-Protection: 1; mode=block → Protección XSS legacy
   ✅ Referrer-Policy: strict-origin-when-cross-origin
   ✅ Permissions-Policy: Restringe geolocation/camera/micrófono
