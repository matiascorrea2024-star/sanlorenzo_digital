# San Lorenzo Digital — Versión Maestra

Esta entrega parte del proyecto real recibido y conserva la arquitectura existente de Next.js + Supabase.

## Arranque

```bash
cd sanlorenzo_digital
nvm use 22
npm install
npm run dev
```

## Producción

```bash
npm run build
npm start
```

## Qué se mejoró visualmente

- Home dark premium mobile-first.
- Header responsive con navegación móvil.
- Hero principal con buscador y búsquedas populares.
- Estadísticas visuales.
- Categorías navegables.
- Cards de negocios renovadas.
- Bloque de promociones/novedades.
- Acceso al mapa.
- Sección Cómo funciona.
- CTA para comercios.
- Footer completo.
- Sistema visual global con profundidad, bordes, glow y grid sutil.

La capa de datos, Supabase, dashboard, miniweb, mapa y rutas existentes se mantienen como base funcional para seguir evolucionando sin reemplazar el backend.
